仅涵盖了区分器的搜索，还包括了区分器两端的扩展部分，用于对SKINNY系列密码算法进行不可能差分攻击。
This project is the experimental code for the paper "Generalized impossible differential attacks on block ciphers: application to SKINNY and ForkSKINNY". It implements an integrated search model that not only covers the search for distinguishers but also includes the extension parts on both sides of the distinguisher, enabling impossible differential attacks on the SKINNY family of block ciphers.
